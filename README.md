# 멀티태스킹 미니게임 (Multitasking Minigame)

> 6개의 미니게임을 동시에 수행하며 
> 우주선을 조종하는 WebGL 게임

## 플레이
https://moonmogun.itch.io/hardle-with-care-demo

## 게임 소개
6개의 모니터에서 서로 다른 미니게임을 동시에 수행해야 하는 멀티태스킹 게임입니다.
현재 튜토리얼 버전으로 배포되어 있습니다.

## 기술 스택
Unity / C# / Unity WebGL

## 담당 구현
- 상속 및 이벤트 기반 미니게임 연동 구조

- 6개 모니터 독립 게임 로직
